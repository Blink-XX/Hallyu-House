# Report Screenshot Placeholder Guide

Replace the bracketed placeholders in the report template with screenshots captured from your own running website. Do not submit placeholder images as evidence.

Suggested captures:
1. Home page (desktop, 1280px).
2. Shop page showing search, filters and sorting.
3. Product details showing price, stock and quantity rule.
4. Bag showing selected items, quantities and delivery calculation.
5. Checkout with validation feedback.
6. Confirmation page after a valid simulated order.
7. Empty search results.
8. Mobile layout at 390px.
9. Browser console with no application errors.
10. Terminal output showing successful `npm test` and `npm run build`.

Also capture three reference-site screenshots for the investigation section. Use actual publicly accessible websites and accurately describe what you observe. Do not invent usability problems or claim an issue exists without evidence.
